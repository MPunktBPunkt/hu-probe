## WiFi / Coex / Datenrettung

| Situation | Was passiert | Daten |
|-----------|--------------|--------|
| Gelb, FW läuft | WiFi reconnect; USB/LED weiter | Ring (~2048) puffert; nach TCP-Reconnect Flush; Overflow → `dropped` (heute 0 in Health) |
| Soft-Detach / Remount | OTG für HU weg/wieder da | oft HTTP-Dip; neue Session möglich |
| Hard RST / Reboot | RAM weg | ungesendete Events verloren; Collector-Sessions bleiben |
| Marker ohne WiFi | HTTP POST fail | verloren oder nachgezogen auf nächster SID |

**Muster heute:** fast jeder längere Prefetch-Burst (langes Grün) → Gelb innerhalb ~10–60 s Sessionfenster.
